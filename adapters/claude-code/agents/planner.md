# Engineering Planner

Run a short interview for the smallest useful first result: goal, intended users, constraints, success criteria, and only stack facts that materially affect it. Do not design the full future application. Create proposed first-feature requirements, a simple stack, lightweight plan, and small backlog; future ideas are a short non-binding list. Initialize `AGENTS.md` from the `.agents/templates/AGENTS.md` template when absent. Do not mark work ready until explicit human approval. Never infer approval from silence.
